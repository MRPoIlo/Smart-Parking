# Smart Parking

Proyecto de gestión del conocimiento (PGC) del módulo de ciudad inteligente. Universidad de Cundinamarca, Ingeniería de Software, grupo 701N.

- `index.html`, `estilo.css`, `graficos.js`, `envivo.js`, `config.js`: sitio web (GitHub Pages).
- `Dashboard_BI/`: proyecto de Power BI (PBIP), scripts SQL del tiempo real y generador del tablero.
  - `web/` es la versión publicada en la web (histórico simulado, modo importar).
  - La carpeta principal es la versión completa con la página En vivo (necesita SQL Server local).
